  ⚬ Automatically prepend #ifdef GL_ES\nprecision highp float;\nprecision highp int;\n#endif\n to fragment shaders if not explicitly declared, preventing mediump precision drift between macOS GPUs and Windows GPUs.

C. Live GLSL Hot-Reloading & Uniform Helper (window.ideShader in sandboxPreload.js)

Expose window.ideShader to p5.js sketches to make shader workflows effortless:

⚬ ideShader.load(p5Instance, vertPath, fragPath):
  ⚬ Loads and preprocesses the vertex and fragment shaders (resolving #includes).
  ⚬ Registers the shader pair with the IDE's file watcher.
  ⚬ Stateful Hot-Reload: When the user edits and saves any .frag, .vert, or included .glsl file in Monaco, re-fetch and re-compile the shader in the active WebGL context on the fly without reloading the page or resetting frameCount, millis(), Audio streams, or OSC state. If compilation fails, keep the last valid compiled shader running so the visual never crashes to a blank screen, and send the compiler log to Monaco.
⚬ ideShader.bindStandardUniforms(shaderObj, p5Instance):
  ⚬ Automatically binds every frame:
    ⚬ u_resolution: [width, height]
    ⚬ u_time: deterministic time in seconds (millis() / 1000.0)
    ⚬ u_delta: deterministic delta time in seconds (deltaTime / 1000.0)
    ⚬ u_frame: integer frameCount
    ⚬ u_mouse: [mouseX / width, 1.0 - (mouseY / height)]
    ⚬ u_rms, u_sub, u_bass, u_lowMid, u_mid, u_highMid, u_treble: floats (0.0 to 1.0) from ideAudio
    ⚬ u_audioTex: the 1024x2 WebGL texture containing full FFT spectrum and Waveform!

D. Dual-Mode Audio-Reactive Engine + WebGL Audio Texture (sandboxPreload.js)

Expose window.ideAudio operating identically in Mode 1 (Real-Time Live Input / File) and Mode 2 (Deterministic Offline Video Export):

1. Real-Time Live Input Mode

⚬ Enumerate hardware/virtual audio input devices (BlackHole, Loopback, VB-Cable, audio interfaces) and open getUserMedia with DSP filters disabled (echoCancellation: false, noiseSuppression: false, autoGainControl: false, sampleRate: 48000).
⚬ Connect to AnalyserNode (fftSize = 2048, smoothingTimeConstant = 0.8).
⚬ When "Record Take (Audio + OSC)" is active, capture raw Float32Array PCM via AudioWorkletNode and write a lossless 32-bit float .wav file (take_audio.wav) into .takes/.

2. Deterministic Offline DSP Mode (Used during Video Export)

⚬ Load the raw PCM Float32Array from take_audio.wav (or an imported .wav file).
⚬ For rendered frame N at target fps, slice 2048 samples ending at sample index \lfloor \frac{N}{\text{fps}} \times \text{sampleRate} \rfloor.
⚬ Apply a Hann Window and execute a complete in-place Radix-2 Cooley-Tukey FFT in pure JS.
⚬ Apply identical exponential smoothing (0.8) relative to frame N-1 so FFT bins, band energies, and RMS match real-time playback deterministically.

3. WebGL Audio Data Texture (ideAudio.getTexture(p5Instance))

⚬ Maintain a dynamic p5.Image (1024 width \times 2 height, RGBA) updated once per frame in both Live and Offline Export modes:
  ⚬ Row 0 (y = 0): 1024 FFT frequency bins normalized 0..255 stored in the R channel (with smoothed peak-hold in G channel).
  ⚬ Row 1 (y = 1): 1024 time-domain Waveform samples mapped 0..255 (where 128 = zero crossing) stored in the R channel.
⚬ Configure texture parameters to NEAREST / LINEAR filtering and CLAMP_TO_EDGE so inside any .frag shader the user can write:
  float fftVal = texture2D(u_audioTex, vec2(uv.x, 0.25)).r;
  float waveVal = (texture2D(u_audioTex, vec2(uv.x, 0.75)).r - 0.5) * 2.0;
  

Unified window.ideAudio Methods:

⚬ ideAudio.getRMS(), ideAudio.getFFT(), ideAudio.getWaveform(), ideAudio.getEnergy(bandOrLowHz, highHz), ideAudio.isBeat(threshold, minIntervalMs), and ideAudio.getTexture(p5Instance).

⚬ Bind UDP socket in Electron Main (configurable RX port default 9000, TX port 9001).
⚬ Record incoming OSC messages { timestampMs, address, args } to take_osc.json during "Record Take".

⚬ Replay recorded OSC messages deterministically at virtual timestamp t_N = \frac{N}{\text{fps}} \times 1000 ms during offline video export.

F. Deterministic Pixel-Perfect Video Exporter for 2D & WebGL (ffmpegExporter.js)

Implement a strict Frame-by-Frame Lockstep Renderer:

1. In the Sandbox window:
  ⚬ Force pixelDensity(1) and exact target width x height.
  ⚬ Call noLoop() and override performance.now(), Date.now(), millis(), deltaTime, and frameCount based on virtual frame N.
2. Dual Context Pixel Extraction (2D vs WebGL):
  ⚬ If the p5 canvas uses a 2d context: extract ctx.getImageData(0, 0, W, H).data.
  ⚬ If the p5 canvas uses a webgl / webgl2 context:
    ⚬ Call gl.finish() to ensure all fragment shader pipelines have completed for frame N.
    ⚬ Read raw pixels via gl.readPixels(0, 0, W, H, gl.RGBA, gl.UNSIGNED_BYTE, rawBuffer).
    ⚬ Fast Vertical Flip in Memory: Because WebGL readPixels uses a bottom-left origin, flip the rows of rawBuffer vertically in-place (swapping row y with row H - 1 - y) before sending over IPC to Electron Main.
3. Pipe the exact RGBA buffer to ffmpegProcess.stdin (using ffmpeg-static) with strict drain backpressure awaiting between frames, muxing the high-res .wav audio track and supporting:
  ⚬ H.264 Master (yuv420p, CRF 15)
  ⚬ H.264 Chroma-Pure (yuv444p, CRF 14 - zero color bleeding on sharp shader edges)
  ⚬ Apple ProRes 4444 + Alpha (yuva444p10le, pcm_s24le - transparent background shader export on both macOS and Windows)
